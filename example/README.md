# Outlined Text Example

This is a basic example demonstrating the usage of `@donkasun/react-native-outlined-text` library.

## Features Demonstrated

- Basic outlined text with different colors
- Various font sizes and stroke widths
- Both `OutlinedText` and `SvgTextOutlined` components
- Different color combinations

## Running the Example

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Run on your preferred platform:
   - iOS: `npm run ios`
   - Android: `npm run android`
   - Web: `npm run web`

## What You'll See

The app displays various examples of outlined text with:
- Different stroke widths (1px to 4px)
- Various color combinations
- Multiple font sizes
- Both component variants

This example shows the basic capabilities of the outlined text library.
