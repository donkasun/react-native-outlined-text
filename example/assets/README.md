# Assets Directory

This directory contains the app assets for the Expo example app.

## Required Assets

The following assets are referenced in `app.json` and should be added:

- `icon.png` - App icon (1024x1024 recommended)
- `splash.png` - Splash screen image
- `adaptive-icon.png` - Android adaptive icon
- `favicon.png` - Web favicon

## Placeholder Assets

For now, you can use placeholder images or create simple ones. The app will work without these assets, but Expo will show warnings.

## Creating Assets

You can create simple placeholder assets using:
- Online tools like Canva or Figma
- Simple colored squares with text
- Or download free icons from sites like flaticon.com

## Asset Sizes

- **icon.png**: 1024x1024 px
- **splash.png**: 1242x2436 px (iPhone X size)
- **adaptive-icon.png**: 1024x1024 px
- **favicon.png**: 48x48 px
